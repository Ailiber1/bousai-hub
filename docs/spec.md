# 防災ハブ 設計書

## 1. 概要

大規模災害時に「どのアプリ・どのページを見ればいいか」で迷わないようにするための、カテゴリ別リンク集約型のランチャーアプリ。

**このアプリ自体は防災データを持たない・生成しない。** 既存の信頼できる防災系サービス(NERV防災、Yahoo!防災速報、電力会社の停電情報ページなど)への「入口」を整理して1箇所にまとめるだけの構成。これにより、外部データ取得や可用性・誤情報リスクを避け、実装をシンプルに保つ。

きっかけ: 2026年7月28日発生の熊本県熊本地方 M7.1・最大震度7の地震(宇城市・氷川町)。

## 2. 対象ユーザー・UI方針

- **老若男女、高齢者や操作に不慣れな人でも直感的に使えること**が最重要要件
- 大きな文字・大きなタップ領域・高コントラスト・シンプルな線のアイコン・最小限のテキスト・余白を多めに
- 写真調ではなくベクター調のフラットUI(装飾より視認性・タップしやすさを優先)

## 3. アプリ形態

- **PWA**(スマホのホーム画面に追加できる形)
- 単一HTMLファイル(HTML/CSS/JS内包) + `manifest.json` + Service Worker(オフラインでも画面自体は表示できるようキャッシュ)
- バックエンドなし。地域選択などの状態は `localStorage` に保存し、次回起動時に自動反映
- ホスティングは GitHub Pages(無料枠)

## 4. 画面構成

### 4-1. トップ画面
- ヘッダー: アプリ名「防災ハブ」(左) + 現在地域表示(右、例:「熊本県」)
- 災害種別トグル(手動選択、4つの大きなチップ): 「地震」「大雨・洪水」「停電」「断水」
  - タップした災害種別に対応するカテゴリカードが**一番上に移動し、赤枠で強調表示**される
  - 外部データ取得は行わない(利用者が今の状況を自分で選ぶだけ。オフラインでも確実に動作する)
- カテゴリカード一覧(下記5.のカテゴリを表示。アイコン+タイトル+短いサブタイトル+タップで詳細画面へ)
- フッター: 「地域を変更」ボタン

### 4-2. カテゴリ詳細画面
- 戻る矢印 + カテゴリ名
- 「開くアプリを選んでください」
- カテゴリ内の子アプリ/リンクを大きなカードで縦に並べる。タップで該当の公式URLへ遷移(6.の仕組み参照)

### 4-3. 地域を変更画面
- 戻る矢印 + 「地域を変更」
- 都道府県検索ボックス + 都道府県リスト(選択中の県は赤背景+チェックマーク)
- 「決定」ボタンで確定 → `localStorage` に保存 → 以後トップ画面・各リンクに自動反映

参考画像: `docs/mockup-top.png`(トップ画面) / `docs/mockup-detail-region.png`(①カテゴリ詳細画面 ②地域変更画面)

## 5. カテゴリ構成(確定)

| カテゴリ | 内容 | リンク方式 |
|---|---|---|
| 地震・気象速報 | NERV防災 / Yahoo!防災速報 / NHKニュース・防災 | 全国共通の固定URL |
| 避難所・避難情報 | 選択都道府県の避難所開設情報 | 市区町村単位の固定URL管理はしない(1700以上あり非現実的・リンク切れリスクも高いため)。「選択都道府県名 + 避難所 開設情報」の検索リンクとする |
| 停電情報 | 選択都道府県に対応する電力会社の停電情報ページ(例: 熊本県→九州電力送配電) | 全国10電力会社の固定URLに、都道府県→電力会社の対応表でマッピング |
| 給水・食料配布 | 選択都道府県の給水・食料配布情報 | 避難所と同様、「選択都道府県名 + 給水 食料配布情報」の検索リンク |
| 通信手段(ネットが使えない時) | 00000JAPAN(災害時無料Wi-Fi)の説明・使い方 / 災害用伝言板web171・災害用伝言ダイヤル171 | 全国共通の固定URL。災害種別に関わらず常時表示 |

## 6. 外部アプリへの遷移の仕組み

各カードは対象サービスの**通常のhttps公式URL**にリンクするだけで、防災ハブ側で特別なディープリンク実装は行わない。

- **インストール済みの場合**: iOS/AndroidのOS標準機能(ユニバーサルリンク/アプリリンク)により、対応済みアプリがあればOSが自動判定し、ブラウザを経由せずアプリが直接開く
- **未インストールの場合**: 通常のWebページが開く(多くの場合そこにアプリストアへの誘導が表示される)
- この挙動は各サービス側の実装に依存する(防災ハブ側でコントロール不可)。ただし主要アプリ(NERV防災・Yahoo!防災速報・NHK等)は概ね対応している

## 7. 災害種別ハイライトの仕組み(確定: 手動選択方式)

- 利用者がトグルで今の状況(地震/大雨・洪水/停電/断水)を選ぶと、対応カテゴリが上部固定+強調表示される
- 気象庁等の外部データ取得は行わない(自動検知方式は不採用。理由: CORS対応・取得失敗時のフォールバックなど複雑さが増し、単一HTML+GitHub Pagesという軽量構成から外れるため)
- 通信手段カテゴリは災害種別に関係なく常に表示する

## 8. 地域データ

- 都道府県選択(47都道府県)を `localStorage` に保存
- 都道府県 → 電力会社(10社)の対応表を静的データとして保持
- 都道府県名は避難所・給水カテゴリの検索リンク生成にも使用

## 9. セキュリティ・運用方針

- 無料枠のみ(GitHub Pages)。バックエンドなし、ユーザーデータの収集・送信は行わない(全てブラウザのlocalStorageに閉じる)
- GitHubリポジトリはPrivateで作成
- シークレット・APIキー等は使用しない(全て公開情報へのリンクのみのため)
