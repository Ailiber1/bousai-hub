# 配布用の素材

防災ハブは検索で見つけてもらうアプリではなく、**人から人へ渡してもらう**ことで広がることを想定している（被災した家族 → 知人 → 口コミ → 自治体）。そのために、渡せる形の素材をここに置いている。

## ファイル

| ファイル | サイズ | 用途 |
|---|---|---|
| `bousai-hub-qr-card.png` | 1080×1080 | **説明入りカード。** LINEなどでそのまま送る用。受け取った人が「これは何か」を一目で分かるようにしてある |
| `bousai-hub-qr.png` | 1200×1200 | QR単体。すでに説明した相手に送る、印刷して貼るなど |
| `qr-card.html` | — | カードの生成元。文言や見た目を直したいときはこれを編集する |

どちらの画像も **`https://ailiber1.github.io/bousai-hub/` を指していることを実際に読み取って確認済み**。

## なぜQR単体ではなくカードを用意しているか

QRコードだけを送られても、多くの人は読み取らない。「何のQRか分からないものはスキャンしない」のが普通の警戒心であり、むしろ健全な反応。

カードには次を入れてある。

- 市区町村を選ぶだけで必要なページが開くこと
- 避難所・給水・停電・連絡手段という具体的な中身
- **ずっと無料**であること
- ホーム画面への追加手順（災害が起きてからでは間に合わないため、平常時に入れてもらう）

## 作り直す手順

URLを変えた場合や、文言を直した場合は次の手順で作り直す。**外部サービスやパッケージのインストールは不要**で、macOS標準のCore Imageだけで完結する。

```bash
# 1. QRコードを生成する
swift tools/make-qr.swift docs/share/bousai-hub-qr.png

# 2. 生成したQRが正しいURLを指すか必ず検証する
#    （誤ったQRを配ると災害時に実害が出るため、この工程は省略しない）
swift tools/read-qr.swift docs/share/bousai-hub-qr.png

# 3. カード画像を作り直す
#    docs/share/ をローカルサーバーで開き、1080x1080で qr-card.html を撮影する
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/share
#    → http://127.0.0.1:8765/qr-card.html を 1080x1080 で保存

# 4. カードの中のQRも読み取れるか検証する
swift tools/read-qr.swift docs/share/bousai-hub-qr-card.png
```

URLを変更する場合は `tools/make-qr.swift` の `url` と、`qr-card.html` の末尾に表示しているURLの両方を直すこと。
