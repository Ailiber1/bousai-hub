# 防災ハブ (Bousai Hub)

災害のときに「どのアプリ・どのページを見ればいいか」で迷わないための、カテゴリ別リンク集約型のPWA。

**このアプリ自体は防災データを持たない。** 既存の信頼できるサービス（NERV防災、Yahoo!防災速報、電力会社の停電情報、内閣府・国交省の公的発表など）への入口を整理して1箇所にまとめている。

## 特徴

- **災害種別を選ぶと、必要なカテゴリが一番上に来る**（地震／大雨・洪水／停電／断水）
- **都道府県を選ぶと、停電情報が対応する電力会社のページに切り替わる**（全国10社）
- **ホーム画面に追加できる**（PWA）。一度開けば、通信できない状況でも画面自体は表示される
- **高齢者・操作に不慣れな人でも使えること**を最優先（大きな文字・大きなタップ領域・高コントラスト）

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 本体。HTML/CSS/JS をすべて内包した単一ファイル |
| `manifest.json` | ホーム画面追加の設定 |
| `sw.js` | Service Worker（オフライン表示） |
| `icons/` | アプリアイコン |
| `docs/spec.md` | 設計書 |

バックエンドなし・外部ライブラリなし・ビルド不要。静的ホスティングにそのまま置ける。

## 設計上の要点

公的機関の災害ページには、常設の入口（**恒久リンク**）と、その災害専用に作られたURL（**災害別リンク**）の2種類がある。後者を埋め込むと次の災害で死にリンクになるため、**このアプリは恒久リンクだけをハードコードし、市区町村レベルの情報は検索リンクに逃がしている**。詳細は [docs/spec.md](docs/spec.md) の第5章を参照。
